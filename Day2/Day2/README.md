# HisabDo AI/ML Internship — Day 2 Task
### Student Data Analysis using Python & Pandas

## 📌 Objective
Practice Python fundamentals (variables, data types, lists, dictionaries, loops, functions)
and get introduced to **Pandas** for basic data handling and analysis.

## 📂 Files
- `student_data_analysis.py` — main script containing the full task solution

## 🧠 What the Script Does
1. Stores data for 10 students (Name, Age, Course, Marks) using a Python dictionary
2. Converts the dictionary into a **Pandas DataFrame**
3. Displays all students
4. Filters and displays students with marks above 70
5. Calculates the average marks of all students
6. Finds the student with the highest marks
7. Finds the student with the lowest marks
8. Displays the total number of students

## ▶️ How to Run
```bash
pip install pandas
python student_data_analysis.py
```

## 🛠️ Tech Used
- Python 3
- Pandas

## ✅ Note
No ML model was used in this task — the focus was purely on Python + Data Handling using Pandas,
as required for Day 2 of the internship.
