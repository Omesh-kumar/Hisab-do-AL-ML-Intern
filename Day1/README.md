# HisabDo Internship Bootcamp — Day 1 (AI/ML Track)

This repository contains my Day 1 submission for the HisabDo Internship Bootcamp (AI/ML Track).

## 📁 Contents

- **student_info_app.py** — Python practical task that:
  1. Takes basic information from the user (name, age, city, marks)
  2. Stores information using variables and a list of dictionaries
  3. Uses if/else conditions (grading logic + pass/fail message)
  4. Uses a loop (to collect multiple students and display the final report)
  5. Uses functions (`get_grade()` and `display_student()`)
  6. Displays a final formatted output/report

- **AI_ML_Concepts.md** — Notes covering:
  - What is Artificial Intelligence?
  - What is Machine Learning?
  - Difference between AI and ML
  - What is Deep Learning?
  - What is Generative AI?
  - Real-world examples of each

## ▶️ How to Run

```bash
python3 student_info_app.py
```

You will be prompted to enter student details one at a time. Type `yes` to add another student, or `no` to finish and view the final report.

## 🛠️ Requirements

- Python 3.x (no external libraries required)
